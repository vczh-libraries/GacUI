## Milestone

- Support touch input so that GacUI is able to work on phone.
- Support reactive layout in easy layout.
- Rewrite `GacBuild.ps1` and `GacGen.ps1` in C++:
  - The new tool will be `GacBuild.exe`.
  - It accepts requires argument:
    - `-mode:(GacBuild|GacGen)` to replace either script.
      - `GacBuild.ps1` calls `GacGen.ps1`, but GacBuild mode does not launch new `GacBuild.exe`, instead it calls the `RunGacGen` function.
    - `-pathGacGen:"absolute path"`
    - `-pathCppMerge:"absolute path"`
    - These paths should be absolute paths and will be checked, it doesn't assume where the tool is.
  - `GacBuild.ps1` and `GacGen.ps1` remain and become wrappers to call `GanBuild.exe`
    - Arguments should not change.
    - `GacBuild.exe` should produce exactly same log files otherwise `GacGen.exe` wont work.
  - In `Release` repo equivalent `GacBuild.sh` and `GacGen.sh` will be created. Powershell versions will be updated from `Tools` like today.
  - Wrapper scripts know and calculate absolute paths to pass to the GacBuild tool.
