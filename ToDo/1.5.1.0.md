# 1.5.1.0

## New Feature

- **VlppReflection** and **Workflow**
  - Support `vl::Variant<Ts...>` but:
    - No nested variant.
    - No implicit conversion around variants in Workflow scripts, offered explicit type conversions.
  - `vl::Variant<Ts...>` not supported in Workflow RPC. But you can grab the payload from a variant with `variant in` operator before passing it.
- **GacUI**
  - `GacBuild.ps1` and `GacGen.ps1` are rewritten into the `GacBuild` tool.
    - `GacBuild.ps1` and `GacGen.ps1` remain for backward compatibility and they become a thin wrapper.
    - `GacBuild.sh` for Linux/macOS.
  - Enhanced `<Raw/>` element:
    - `<Raw/>` maps to one of the following elements, in native renderer with or without native renderer:
      - `GuiDirect2DElement`
      - `GuiGDIElement`
      - `GuiWaylandElement`
      - `GuiCocoaElement`
    - `<Raw/>` has `Id` and `Data` properties, changing them triggers repaint, or syncing data to remote protocol renderer, so that customized rendering could be done remotely.
    - `GuiRemoteRendererSingle` exposed `GetRawElements` method, as well as `RawElement(Installed|Uninstalled|Changed)` events as helpers.
    - TUI does not support `<Raw/>` element.
  - Touch experience on Windows, remote protocol and GacJS.
    - New events:
      - `pointSequenceStarted`
      - `pointAction`
      - `pointGesture`
      - `pointSequenceEnded`
    - The following controls support touch experiences by default:
      - `GuiScrollView`.
- **Release** for new tutorials:
  - `GacUI_Windows/RawClock`
  - `GacUI_Windows/Touching`
  - `GacUI_Windows/TouchingList`
  - `GacUI_Layout/Responsive3`
