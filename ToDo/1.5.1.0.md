## Fixed Bugs

## Milestone

- Support touch input so that GacUI is able to work on phone.
  - Use point as the term as we dont use legacy touch on both Windows and browser.
  - Add all point and gesture events to `INativeWindowListener`.
    - Implement on Windows, remote protocol, GacJS.
    - Not implement on Linux, macOS.
  - A point sequence begin and point sequence end event before and after a series of point events, when an event share at least one finger with the next event.
    - Point sequence begin starts with the first finger, it will be used to query id that position supporrs touching, responsing "No" will stop reporting all following events.
    - A sequence has an unique id per native window.
    - Not supported sequence begin also denies gesture.
  - Apply momentum scrolling and long pressing on list and document, including selection.
    - One more test page and tutorial to demo deleting and dragging list items.
    - Another test page and tutorial to demo dragging and rotating a polygon.
  - Fix automation service to support touching anf gesture.
  - Fix UIA with touching and gesture experience if doable.

- Author a complete `GacUIMVVM.md`.
- Add `Release/Tutorials/GacUI_Layout/Responsive3` with the main window in `EasyLayoutResponsiveWindow.xml` and other necessary files from `FullControlTest`.
  - Run `Build.ps1 -Project GacUI` and `Build.ps1 -Project Release` to make sure everything works.
  - Update the website and existing documents (if any) to reflect the change.
