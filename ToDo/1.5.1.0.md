# 1.5.1.0

## New Feature

- **GacUI**
  - `GacBuild.ps1` and `GacGen.ps1` are rewritten into the `GacBuild` tool.
    - `GacBuild.ps1` and `GacGen.ps1` remain for backward compatibility and they become a thin wrapper.
    - `GacBuild.sh` for Linux/macOS.
  - Enhanced `<Raw/>` element:
    - `<Raw/>` maps to one of the following elements, in native renderer with or without native renderer:
      - `GuiDirect2DElement`
      - `GuiGDIElement`
      - `GuiWaylandElement`
      - `GuiCocoaElement`
    - `<Raw/>` has `Id` and `Data` properties, changing them triggers repaint, or syncing data to remote protocol renderer, so that customized rendering could be done remotely.
    - `GuiRemoteRendererSingle` exposed `GetRawElements` method, as well as `RawElement(Installed|Uninstalled|Changed)` events as helpers.
    - TUI does not support `<Raw/>` element.
