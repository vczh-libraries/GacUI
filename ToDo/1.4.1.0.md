# 1.4.1.0

## New Feature

- **VlppReflection**:
  - `GenerateMetaonlyTypes` accepts `excludedTypes` so that `ITypeManager` could be dumped to multiple binary files with dependencies.
- **GacUI**:
  - **GacGen** supports Workflow RPC code/metadata generation.
- **Workflow** and **GacJS**:
  - Offer material for building Workflow RPC supports for other programming languages.
  - **GacJS** leverage the same support to enable GacUI view model implemented in TypeScript.
