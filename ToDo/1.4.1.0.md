### GacJS with ?rvmhost

- GacJS with `?rvmhost`:
  - New codegen package `Gaclib/gaclib/codegen-workflow-rpc`.
    - When `Gaclib/shared/codegen` runs it, it should offer two files: `GacUI\Test\GacUISrc\Generated_RemoteViewModelTest\Resource_x86\RpcMetadata.(txt|d.ts)`.
    - Generate `Gaclib/website/rvm`, with all source code needed to host the `IViewModel` interface.
    - `rvmhost` relies on `Gaclib/website/remote-protocol-http`.
  - Modify `Gaclib/website/remote-protocol-http`:
    - Separate HTTP protocol implementation with actual remote protocol renderer handling.
    - The remote protocol renderer handling uses the HTTP protocol implementation, no inheritance.
  - New package `Gaclib/website/rvm`:
    - Export all necessary files.
  - New package `Gaclib/website/rvmhost`:
    - Start `rvm` as a separate process, just like `RemotingTest_RvmHost`, to connect `RemotingTest_Core`.
  - `?rvmhost` in website path:
    - Start `rvm` in the webpage to connect `RemotingTest_Core`, but renderer and rvm use different client.
- Update `DebugRemoteProtocolWithGacJS.md` to mention this.
- Run through the verification on:
  - Windows
  - Linux
  - macOS
