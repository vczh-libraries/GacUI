# 1.5.2.0

## New Feature

- **GacUI**:
  - `GuiFakeDialogService` allow file dialog to new folder, delete folder and delete file.
  - `IGuiGraphicsRawInterpretor(Factory)?` and `IGuiGraphicsResourceManager::(Register|Get)RawInterpretorFactory`. Combining with `GuiRawElementBase::Interpretor` property you could register renderer for a certain group of raw elements. `Interpretor` property could be used in GacUI XML Resource directly, making the XML and its generated C++ code cross platform.
- **GacJS**
  - Make text box works for IME and virtual keyboard.
