# 1.5.2.0

## New Feature

- **Workflow**:
  - When generated user methods have breaking change causing invalidating user added code in generated files, method signature is always added in the "unused" block for de-ambiguity.
- **GacUI**:
  - In remote protocol, both core and renderer can decide if date time, locale or file system is allowed to use the renderer side implementation.
    - Both native renderer and `GacJS` implement this feature.
    - Renderer side implementation is only picked up when both core and renderer allow.
    - WASM doesn't have such mechanism because core and renderer is always running in the same browser environment.
