### TUI (VlppOS)

- TUI on `VlppOS` to complete all IO including typing/key/mouse/wheel.
  - Move `VKEY` and native key/mouse/input structures from `GacUI` to `VlppOS`.
    - Complete list:
      - `GuiCoordinate`, `NativeCoordinate` and `CompareCoordinate`.
      - `NativeMouseButton`, `WindowMouseInfo_` and its usings.
      - `NativeWindowKeyInfo` and its usings.
      - `NativeWindowCharInfo` and its usings.
      - `GUI_DEFINE_KEYBOARD_CODE_BASIC`, `GUI_DEFINE_KEYBOARD_CODE_ENUM_ITEM`, operator on VKEY.
      - If there is any comments, they must also be moved.
      - They must be organized in one dedicated file, e.g. `TUITypes.h`, everything will be still under `vl::presentation`.
    - Document in `VlppOS/AGENTS.md` that GacUI is using these types, be awared of breaking changes.
  - Existing types in TUI will be replaced by new types moved from GacUI.
- TUI playground
  - Currently only and simple type-to-draw UI. I would like you to add 3 tabs:
    - first for canvas, second for command history, third for drop down menu selecting a shape and draw with mouse.
    - First tab for the current UI called "Canvas".
    - Second tab for command history called "History".
    - Third one is actually not behaves like a tab, called "Shapes", but when tab to it or click it:
      - All available shape listed (LINEV, LINEH, RECT, with options flattened in one list), up/down/click to select.
      - When selected, if the current tab is not "Canvas", jumps to "Canvas", and gray out the textbox (background is already gray so only gray the text to feel like disabled) until drawing is done.
      - Now mouse could drag a rectangle, when dragging the shape should be visible and moving with the mouse, when release the shape is actually draw to the canvas.
    - tabs are rendered as blue background white text for selected, gray background white text for unselected, from left to right on the first line, each one surrounded by a space in front and end.
    - TAB key or mouse click to switch berween tabs.
    - Only left mouse button is working through out the app.
    - wheel to scroll history.
  - SOP for manual testing TUI test app.
    - In `VlppOS/.github/Jobs/DebugTuiPlaygroundSOP.md`, just like how `GacUI/.github/Jobs/DebugRemoteProtocolSOP.md` is organized.
    - Update `VlppOS/Project.md` to reference the sop document, some content is in `Project.md` already, but I don't want to mix them in one single file.
- Release `VlppOS` to `GacUI`, fix `GacUI` to make sure it works. By just moving types it should be fine to compile everything and only run unit test for verification.
