# 1.4.1.2

## New Feature

- **VlppOS**
  - Complete cross-platform TUI interface with typing/keyboard/mouse/wheel support, starting from:
    - `TUI::Start`
    - `TUI::InstallListener`
    - `TUI::UninstallListener`
- **GacUI**
  - GacUI on TUI, available on Linux and macOS.
  - `Gui(Open|Save)FileDialog` displays the `FileName` property initially.
  - `GuiApplication::RefreshThemes` to change theme app-wide after global theme options is changed.
  - `DarkSkin` and `TuiSkin` predefine multiple color theme, check out `(darkskin|tuiskin)::Create*ColorPackage` and `(darkskin|tuiskin)::SetColorPackage`.
    - After calling `SetColorPackage`, `GuiApplication::RefreshThemes` is required to call immediately, strongly recommended to pair with `GetApplication()->InvokeInMainThread` even when you are already in the UI thread.
